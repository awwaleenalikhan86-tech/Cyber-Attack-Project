💡 How Does Live Prediction Work?
1
Enter Values
Fill in the network connection features, or click a Sample Data button to auto-load example data.
2
Standardize
Features are scaled using the training dataset's mean & standard deviation (StandardScaler).
3
Compute Score
The LR model computes: z = w₁x₁ + w₂x₂ + … + b using trained coefficients.
4
Sigmoid → Verdict
P(attack) = σ(z) = 1/(1+e⁻ᶻ). If P > 0.5 → Attack flagged. Otherwise → Safe.
